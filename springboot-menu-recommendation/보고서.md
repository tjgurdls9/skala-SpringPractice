# 백엔드 2일차 실습 보고서 — 오늘 뭐 먹지?

## 1. 기존에 구현되어 있던 기능

실습 시작 시점에 이미 만들어져 있던 API입니다.

| API | 설명 |
| --- | --- |
| `GET /api/hello/{name}` | 이름을 받아 인사말 반환 |
| `GET /api/menu` | 고정된 기본 추천 |
| `GET /api/menu/random` | 메뉴 목록 중 무작위 추천 |
| `GET /api/menu/{category}` | `korean`/`chinese`/`japanese`/`snack` 카테고리별 추천 |
| `GET /api/menu/json/{category}` | 카테고리별 추천을 JSON(`MenuResponse`)으로 응답 |

Component Scan으로 등록된 `MenuService` Bean을 `MenuController`가 생성자 주입으로 사용하는 구조를 학습했습니다.

## 2. 실습과제로 직접 구현한 API (4개)

| 과제 | API | 로직 |
| --- | --- | --- |
| ① 날씨별 추천 | `GET /api/menu/weather/{weather}` | `sunny`/`rainy`/`hot`/`cold` → switch 분기 |
| ② 기분별 추천 | `GET /api/menu/mood/{mood}` | `happy`/`sad`/`tired`/`stressed` → switch 분기 |
| ③ 가격대별 추천 | `GET /api/menu/price/search?min=&max=` | `@RequestParam`으로 두 값을 받아 구간별 추천 |
| ④ 나만의 추천 | `GET /api/menu/my/{companion}` | `solo`/`friends`/`family`(같이 먹는 사람 기준, 자유 설계) |

기존 `recommendByCategory` / `menuByCategory`와 동일한 구조(Controller → Service, `@PathVariable`/`@RequestParam`, switch 분기)를 그대로 반복 적용해서 만들었습니다.

## 3. 직접 개선한 부분 (디벨롭)

과제 구현을 마친 뒤, 아래 항목들을 스스로 찾아서 고쳤습니다.

1. **`index.html` 하드코딩 제거**
   원래 실습과제 4개 버튼은 `rainy`, `happy`, `min=5000&max=10000`, `solo`처럼 **고정된 값 하나만** 호출하도록 되어 있었습니다. 이를 버튼을 누를 때마다 유효한 값 후보 중 하나를 무작위로 골라 호출하도록 변경해서, 한 번의 클릭이 아니라 여러 번 눌러보며 각 API의 모든 분기(`switch`의 모든 case)가 실제로 잘 동작하는지 확인할 수 있게 했습니다.

2. **가격대별 추천 로직의 현실성 수정**
   1만원~2만원 구간에 "오마카세"를 추천하도록 되어 있었는데, 실제 가격대와 맞지 않아 "스테이크 정식"으로 수정했습니다.

3. **응답 형식 통일**
   기분별 추천이 다른 API와 다르게 JSON으로 응답하고 있어서, 통일성을 위해 텍스트 응답으로 바꿨습니다.

4. **개발 편의성 패치**
   `./gradlew bootRun`으로 서버를 켤 때마다 브라우저를 직접 열어야 하는 번거로움이 있어서, `build.gradle`의 `bootRun` 태스크에 서버가 응답 가능해지는 순간 자동으로 기본 브라우저에서 `http://localhost:8080`을 열어주는 로직을 추가했습니다 (macOS `open` 명령 사용).

5. **오탈자/띄어쓰기 수정**
   날씨별 추천 응답 문구의 띄어쓰기 오류를 수정했습니다.

## 4. Docker화

프로젝트 루트에 `Dockerfile`(멀티스테이지 빌드)과 `.dockerignore`를 작성했습니다.

- 1단계(`build`): `eclipse-temurin:21-jdk` 이미지에서 Gradle Wrapper로 `bootJar` 실행
- 2단계(실행): `eclipse-temurin:21-jre` 이미지에 결과 jar만 복사해서 용량을 줄임

### 빌드 & 실행 명령어

```bash
docker build -t springboot-menu-recommendation .
docker run -p 8080:8080 springboot-menu-recommendation
```

### 실행 결과 검증

컨테이너를 띄운 뒤 6개 API를 `curl`로 확인한 결과, 전부 정상 응답했습니다.

```text
--- 기본 추천 ---
오늘의 추천 메뉴는 김치찌개입니다.
--- 한식 추천 ---
korean 추천 메뉴는 불고기입니다.
--- 날씨별(맑음) ---
sunny에 어울리는 메뉴는 타코 플래터입니다.
--- 기분별(우울) ---
오늘 기분엔 떡볶이 어떠세요?
--- 가격대별(5천~1만) ---
5000원~10000원 사이 추천 메뉴는 돈가스입니다.
--- 나만의 추천(가족) ---
family이라면 삼겹살 파티 어떠세요?
```

이미지 크기: `springboot-menu-recommendation:latest` (JRE 기반, content 약 141MB).
